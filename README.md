# Mastra Code: Getting Started Tutorial

An interactive, beginner-friendly tutorial for building websites with [Mastra Code](https://docs.mastra.ai/docs/mastra-code/overview). Assumes zero technical background — walks you from "I just have a laptop" to "I just deployed my first website."

## Features

- **OS auto-detection** — shows the right install commands for Mac, Windows, or Linux
- **Progress checklist** — mark steps as done, progress persists across visits
- **Interactive plan picker** — quiz to recommend the right Claude subscription
- **Animated terminal** — see what commands look like before running them
- **Jargon tooltips** — hover/click on any technical term for a plain-English explanation
- **Dark mode** — toggle between light and dark themes
- **"I'm stuck" panels** — common problems and fixes for each step

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and import at [vercel.com/new](https://vercel.com/new) — it auto-detects Next.js and deploys in about 60 seconds.

## Built with

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com) v4
- [next-themes](https://github.com/pacocoursey/next-themes)
- Built entirely using Mastra Code
